# 滅びの呪文

写真を撮って、呪文をひとつ。強い呪文ほど、景色が跡形もなく崩れ落ちるゲーム。

- 写真は「手描きアニメ風」に加工（空を塗り替え、色を段にして線画を足す）
- 呪文の強さは「響き（濁音・破裂音）」「短さ」「物騒さ（漢字・カタカナ語）」「勢い」で採点。理由も表示
- 写真の中の物体と背景を分けて、物体だけが崩れる（消えたところは背景を広げて埋める）
- 消え方は6種類：ひび割れ・粉々・砂になる・ブラックホール・燃えて灰に・溶ける（おまかせもあり）
- 写真はアプリの中だけで使い、保存しません
